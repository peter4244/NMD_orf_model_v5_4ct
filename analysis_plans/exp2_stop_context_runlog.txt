F. THE CONTROL THAT DECIDES WHETHER B IS REAL
================================================================================================

  Added after Experiment 4 measured this machinery's noise floor and
  found it is NOT zero: null arms with no possible mechanism returned
  point estimates of 2-5pp, one of them at p = 0.027. B's +2.00pp sits
  inside that range, so B cannot be read as real on its own.

  The decisive control: run the IDENTICAL contrast -- the 3-mer TGA
  against the 3-mer TAG, same anagram logic, same strata, same
  bootstrap -- at positions in the 3'UTR where neither string is a stop
  codon and no mechanism exists. If those return ~0, the stop-codon
  result stands above the floor. If they return ~2pp, it does not.

    the stop codon itself    n TGA 14,477 TAG  5,818   TGA-TAG =  +2.00pp  CI [ +0.84,  +3.18]  p = 0.001  <-- the claim
    3'UTR +10..+12           too few: TGA 573 TAG 199
    3'UTR +25..+27           n TGA    541 TAG    214   TGA-TAG = +11.66pp  CI [ +3.67, +23.48]  p = 0.007

  Read the +10/+25/+50/+100 rows as the null distribution of this
  exact statistic. The stop-codon row has to stand outside it.
